# Data provenance and access

Historical research used nine COG-BCI MATB Easy .mat/.set file pairs. The raw files have **not** been uploaded to this repository.

Before importing:
1. Confirm licensing, consent, and redistribution terms.
2. Preserve original filenames and file checksums.
3. Document subject identifiers and matching rules without exposing unnecessary personal information.
4. If redistribution is restricted, provide authorized acquisition instructions instead of committing raw files.

Never invent or substitute synthetic data for historical participant recordings without labeling it clearly.
